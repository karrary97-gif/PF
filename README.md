# نظام البصمة – تطبيق ويندوز (FPBridge.exe)

تطبيق واحد مستقل (لا يحتاج بايثون ولا أي تثبيت) يحتوي الوسيط كاملًا + واجهة + أيقونة بجانب الساعة.

## الحصول على ملف exe (مرة واحدة)
1. أنشئ مستودعًا جديدًا في GitHub وارفع محتويات هذا المجلد كما هي.
2. (اختياري، يُنصح به) Settings ← Secrets and variables ← Actions ← New repository secret
   الاسم: `FP_KEY` والقيمة: مفتاح الجسر (64 حرفًا من الدالة showKey). عندها يُدمج المفتاح داخل الـexe ولا يُطلب منك شيء.
3. تبويب **Actions** ← Build Windows EXE ← يعمل تلقائيًا بعد الرفع (أو Run workflow).
4. بعد دقيقتين افتح التشغيلة ← **Artifacts** ← نزّل `FPBridge-windows` وفُكّ الضغط.
   (للحصول على صفحة Releases ثابتة: أنشئ tag مثل `v1.0`.)

## الاستخدام
- شغّل `FPBridge.exe`. إن لم تدمج المفتاح، تظهر نافذة تطلب لصقه مرة واحدة فقط.
- وصّل جهاز البصمة بالشبكة، وعرّفه في الموقع: تبويب «أجهزة البصمة» ← طريقة «وسيط بايثون» (الاسم + IP + المنفذ 4370).
- التطبيق يقرأ قائمة الأجهزة من الموقع تلقائيًا ويسحب كل 15 دقيقة، ويبقى يعمل بجانب الساعة ويبدأ مع ويندوز.
- زر «سحب من الأجهزة» في الموقع يعمل أيضًا لأن التطبيق يخدمه محليًا على 127.0.0.1:8765.
- الحركات تُحفظ محليًا أولًا ثم تُرسل عند توفر الإنترنت (لا تضيع ولا تتكرر).

الملفات والسجل في: `%APPDATA%\FPBridge`

## ملاحظات
- أول تشغيل قد يُظهر تحذير SmartScreen (الملف غير موقّع رقميًا): «مزيد من المعلومات ← تشغيل على أي حال».
- لا تشغّل برنامج ZKTime أو نسخة ثانية من الوسيط على الجهاز نفسه في الوقت ذاته (الجهاز يقبل اتصالًا واحدًا).
- كلمة اتصال الجهاز (Comm Key) إن وُجدت: ضعها في `%APPDATA%\FPBridge\fp_config.json` تحت `comm_keys`.
